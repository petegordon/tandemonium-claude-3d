# Tandemonium geese — roadmap (v2 pipeline, start to finish)

Plan of record for building the Tandemonium characters and bike from the **v3 reference set**
(`refs/v3/`, generated by Pete with Codex image_gen from `refs/v3/source-reference.png`; v2 in `refs/v2/` is superseded).
`PLAN.md` is the pipeline manual and progress log. Every step below is a GitHub issue
(`[Pn.m]` in the title) under a milestone per phase. Each step ends in an **evaluation gate**:
measured checks + renders, and the questions Pete needs to answer before the next step.

## Architecture: one goose, many outfits

- **One base goose** (unclothed, sex-neutral, `refs/v2/mannequin-*.png`) with **one standard rig**,
  shared eyes and beak. "Male" and "female" are **outfits** worn over it (D6).
- **Outfits** are separate skinned garment meshes (coat, waistcoat, shirt/collar, bow tie, breeches,
  gloves, boots, bowler; dress, hat + plume, brooch, gloves, boots), swappable and **recolourable**.
- **Bike** is built separately with rigid moving parts; riders attach at saddle / grip / pedal targets
  (`refs/v2/assembly-turnaround.png`).
- **Budget:** a dressed character ≤ 20k tris (body regions hidden by the outfit are masked/removed);
  one draw call per mesh family; validator-clean GLBs.

Why v2: almost every v3 fix traced back to the old reference sheet (heads turned 15°/38°, painted
lighting, no body under the clothes, two unrelated bodies). The v2 sheets fix that at the source:
front-facing heads, soft even light, one shared body, clothed views drawn over that body.

## Decisions so far (Pete)

| | Decision |
|---|---|
| D1 | The base goose defines scale; absolute game height is set with the bike. |
| D2 | Eyes: oval opening, lids and colours from the reference; identical on every goose (shared asset). |
| D3 | New standard rig (humanoid naming + goose extras), not the Track 1/Track 2 rigs. |
| D4 | Skirt / coat tails: bone chains + weight painting, no cloth sim; the mesh must never break. |
| D5 | Wardrobe and colour changes before riding in the game. |
| D6 | One shared base body; male/female are outfits. |
| D9 | Rig: bind pose = model rest pose; Mixamo-style names + goose extras; hip joint 14 cm above the crotch. |
| D8 | Hands are **mittens** (fingers fused; no finger bones) — "They are Canadian Geese." |
| D7 | v3 reference set is the source of truth: 2x2 sheets, one master pose with arms that agree in every view (v2 produced an extra hand per side). Riding/pose sheet deferred until P5. |

## What carries over from v3

The whole pipeline (ComfyUI jobs, review/IoU, clean_hi + fix plugins, retopo_bake, tangent fix,
validator), Instant Meshes integration, the shared-eye work, head-view picking, and the lessons in
PLAN.md. The v3 meshes stay in release `v3-geese` as a fallback / look reference.

## Risks

- **Image consistency** across panels (README in `refs/v2/` warns of small drift) → resolve in 3D; front + profile pair is authoritative.
- **Hands and webbed feet** are thin features the generator may melt → check at P1.3; sculpt/fix plugins.
- **12 GB laptop GPU** → 1024 tier needs Antigravity's ComfyUI and Pete's Blender closed.
- **Garment extraction (P3.3)** is the new technique → prototype on the male coat first.
